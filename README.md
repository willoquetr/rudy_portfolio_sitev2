# Rudy Portfolio (Static Mini‑App)

## Local
- Double‑click `index.html`.
- Or run a small server:
  - `python -m http.server 8000`
  - http://localhost:8000

## Avatar
Place a non‑photorealistic avatar at `assets/avatar.png`.

## Screenshots
Replace placeholders in the modal (search: `Screenshot (placeholder)`) with `<img>` tags.

## Deploy
- GitHub Pages (simple, public repo)
- Netlify (free, can deploy from private repo)
